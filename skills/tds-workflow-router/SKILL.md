# Coordinate TD SYNNEX workflows

Read [shared operating guidance](references/operating-guidance.md). Resolve the user's intended outcome, account, customer and identifiers, then select the relevant workflow.

| User need | Skill |
| --- | --- |
| Find products, compare prices and check availability | discover-products |
| Review or save quotes | manage-quotes |
| Prepare or submit a purchase order | order-submission |
| Track orders and shipments, reconcile invoices or estimate freight | track-orders-invoices-freight |
| Prepare returns and follow RMA requests | manage-returns |
| Find or update customer records | manage-customers |
| Review or change cloud subscriptions | manage-cloud-subscriptions |
| Manage Microsoft users, licenses and delegated access | manage-microsoft |
| Reconcile cloud invoices and charges | review-cloud-billing |
| Analyze Azure usage and consumption | azure-consumption |
| Interpret codes or handle connection and schema questions | tdsynnex-tools |

For sourcing-to-order requests, resolve products, refresh prices and stock, estimate freight, prepare the concrete order, execute only within authorization, and read its status. A quote or comparison request alone does not authorize purchasing.

For returns, establish the original sale and return inputs, select account-supported reason and condition values, prepare the return, and follow the resulting request or authorization. A request number alone is not permission to ship goods back.

For cloud changes, resolve customer and tenant, read subscriptions or Microsoft records, prepare the requested change, follow operation status where available, and verify the resulting record. Keep customer consent and completed provisioning distinct.

Complete independent reads while necessary information is pending. Carry verified identifiers between steps without converting or inventing them. Present one concise result that states what was found, what changed, pending outcomes and any missing prerequisites.
